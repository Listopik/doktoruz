# DoktorUZ — серверная версия

Это следующий этап после локального HTML-прототипа: интерфейс сохраняется, а пользователи, SMS-сессии, врачи, заявки, записи, реклама и админские права хранятся на сервере в PostgreSQL.

## Что переносится на сервер

- Регистрация и вход по телефону.
- OTP-код: демо-режим или реальная отправка через Twilio Verify.
- Пользователи и роли `user/admin/master_admin`.
- Записи с серверной защитой от двойного бронирования.
- Заявки врачей и модерация.
- Каталог врачей, блокировка и удаление.
- Реклама и показ на главной.
- Журнал админских действий.
- Выдача/отзыв админ-доступа по номеру.

## 1. PostgreSQL

Создайте PostgreSQL-базу и получите `DATABASE_URL`.

## 2. Переменные окружения

Скопируйте `.env.example` в параметры окружения проекта и задайте:

- `DATABASE_URL`
- `SESSION_SECRET`
- `ADMIN_PASSWORD_HASH`
- `MASTER_ADMIN_PHONE`
- `SMS_MODE`
- для реального SMS: `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_VERIFY_SERVICE_SID`
- `SETUP_TOKEN`
- `SETUP_ENABLED=true` только на время первичной инициализации

Хэш в `.env.example` соответствует паролю `VERNUS777`.

## 3. Инициализация БД

После деплоя один раз вызовите:

`POST /api/router?action=setup`

с заголовком:

`X-Setup-Token: <ваш SETUP_TOKEN>`

После успешной инициализации выставьте `SETUP_ENABLED=false`.

## 4. SMS

Для безопасного теста оставьте `SMS_MODE=demo` — API вернёт OTP в ответе, чтобы проверить весь поток.

Для реальных SMS установите `SMS_MODE=twilio` и заполните Twilio Verify переменные. Тогда код будет отправляться оператором SMS, а не показываться в интерфейсе.

## 5. Админ-панель

Главный номер: `+998 93 376 3262`.

Пароль хранится только в переменных окружения сервера. Не размещайте его в HTML.

## 6. Медиа-реклама

API принимает URL фото/видео. Для реальной загрузки файлов рекомендуется подключить объектное хранилище/Cloudinary и передавать в `mediaUrl` публичный HTTPS URL.

Небольшие data URL годятся только для тестов; большие видео нельзя хранить в JSON/localStorage.

## 7. Важное перед боевым запуском

Нужно отдельно провести настройку политики персональных данных, резервного копирования, rate limiting, мониторинга, CSP/CORS и защиты файлов.

## Структура для Vercel

В корне должен лежать `index.html`, рядом `remote-app.js`, а API-функция — `api/router.js`.
